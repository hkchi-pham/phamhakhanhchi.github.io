Measured in Phases 1 and 2, not assumed:

- **Deploy latency from push is 112-168 seconds.** Workflow starts ~2s, finishes ~70-140s,
  `gh-pages` advances ~92-150s, and the new CSS is served ~112-168s — the last gap being
  GitHub's separate "pages build and deployment" run, which `deploy.yml` does not wait on.
  **Poll; do not refresh once.** A stale stylesheet at t=120s is not evidence of failure.
- `main.css` is served with `Cache-Control: max-age=600` behind a proxy cache. **Every
  fetch needs `?cb=$(date +%s)`.**
- `_custom.scss` is `@use`d LAST, so its rules land near the END of `main.css` (~97% down).
  Search the stylesheet; do not scroll to the top and conclude the deploy failed.
- `/actions/runs?head_sha=` needs the **FULL 40-character SHA**. A short SHA returns
  `"total_count": 0`, which is indistinguishable from "no run fired".
- The public GitHub REST API is readable **unauthenticated** on this repo (60 req/hr):
  `curl -s https://api.github.com/repos/hkchi-pham/phamhakhanhchi.github.io/actions/runs?per_page=8`.
  The remote org is **hkchi-pham**, not `phamhakhanhchi`.
- Git Bash mangles `git show <rev>:<path>` via MSYS path conversion. Prefix with
  `MSYS_NO_PATHCONV=1`.
- `gsd-tools state update-progress` CORRUPTS this STATE.md and `record-metric` silently
  drops `stopped_at:` and `progress.percent:`. Run `record-metric` only, then
  `git diff .planning/STATE.md` and restore by hand.
- `gsd-tools roadmap update-plan-progress` writes unpredictably and mangles table padding.
  Run it as an oracle for its counts, then edit the row by hand.
- `.planning/**` sits on `deploy.yml`'s `paths-ignore` denylist, so planning-only commits
  fire no deploy — which is why plan 03-01's commits have not deployed anything.

On https://phamhakhanhchi.com/, open DevTools console and paste:

```js
(() => {
  const p = document.querySelector('.post article p');
  const r = document.createRange(); r.selectNodeContents(p);
  const lines = r.getClientRects().length;
  return { chars: p.textContent.trim().length, lines,

})();
```
