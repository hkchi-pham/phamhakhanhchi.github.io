<operational_facts>
Measured in Phases 1-3, not assumed:

- **Deploy latency from push is 112-168 seconds**, with one 75s outlier that does **not**
  re-baseline the band. Workflow starts ~2s, finishes ~70-140s, `gh-pages` advances
  ~92-150s, and the new CSS is served ~112-168s — the last gap being GitHub's separate
  "pages build and deployment" run, which `deploy.yml` does not wait on. **Poll; do not
  refresh once.** A stale stylesheet at t=120s is not evidence of failure.
- `main.css` is served with `Cache-Control: max-age=600` behind a proxy cache. **Every fetch
  needs `?cb=$(date +%s)`.**
- `_custom.scss` is `@use`d LAST, so its rules land near the **END** of `main.css` (~97% down).
  Search the stylesheet; do not scroll to the top and conclude the deploy failed.
- `/actions/runs?head_sha=` needs the **FULL 40-character SHA**. A short SHA returns
  `"total_count": 0`, which is indistinguishable from "no run fired" — four polls were wasted
  on this in plan 01-05.
- The public GitHub REST API is readable **unauthenticated** (60 req/hr). The remote org is
  **hkchi-pham**, not `phamhakhanhchi`:
  `curl -s https://api.github.com/repos/hkchi-pham/phamhakhanhchi.github.io/actions/runs?per_page=8`
- `.planning/**` and `docs/**` are both on `deploy.yml`'s `paths-ignore` denylist, so a commit
  whose entire diff is planning or documentation fires **no** deploy. A commit mixing `docs/`
  with `_sass/` **does** deploy — `paths-ignore` skips only when *every* changed path matches.
- Git Bash mangles `git show <rev>:<path>`; prefix with `MSYS_NO_PATHCONV=1`.
- `gsd-tools state record-metric` drops `stopped_at:`, `resume_file:` and `progress.percent:`
  and rewrites `status: in-progress` to `status: unknown`, on ten consecutive occasions. Run it,
  then `git diff .planning/STATE.md` and restore all four by hand. `advance-plan` and
  `update-progress` refuse outright. `gsd-tools commit` has mis-parsed `--files` and committed
  nothing; use `git commit` directly.
- `gsd-tools roadmap update-plan-progress` writes unpredictably and mangles table padding. Run
  it as an oracle for its counts, then edit the row by hand against the Phase 1 row.
- **Subagents cannot commit under `.github/workflows/`** in this environment. Nothing in this
  plan touches a workflow, so it should not arise.
