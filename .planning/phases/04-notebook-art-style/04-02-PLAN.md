<operational_facts>
- `_sass/_tokens.scss` is **the** literal surface. A hex, rem, em or px in any other `_sass/`
  file is a bug (Phase 2 criterion 5). The data URI is a literal; it belongs here.
- **A data URI cannot be parameterised.** The CSS engine treats the whole URL as one opaque
  string, so `baseFrequency`, `numOctaves` and the rect `opacity` **cannot** be `var()`
  references. CONTEXT's "record the numbers in the token file" is therefore satisfied by a
  comment block above the declaration, in the same style as the `--measure` arithmetic comment
  at `_tokens.scss:158-174` — not by separate tokens. Do not try to build the URL from parts.
- **`#` must be `%23` and `%` must be `%25`.** `#` is the URI fragment delimiter and `%`
  starts an escape; get either wrong and the image simply does not render — no console error,
  no fallback, no CI failure. The page looks exactly as it did before, which reads as "the
  deploy did not ship" and sends you hunting in the wrong place.
- **Pin the filter region.** `<filter>` defaults to `x="-10%" y="-10%" width="120%" height="120%"`,
  so `stitchTiles="stitch"` stitches a 240x240 tile against a 200x200 image and seams every
  200px. `x='0' y='0' width='100%25' height='100%25'` fixes it.
- Dart Sass `--style=compressed` passes custom-property values through verbatim, space after
  the colon included. Prettier at `printWidth: 150` does not rewrap the single-line declaration.
- Nothing in this plan deploys. `_sass/**` is NOT on `deploy.yml`'s denylist, so the commits
  here **would** deploy if pushed — do not push. Plan 04-04 owns the phase's single push.
- `gsd-tools state record-metric` drops `stopped_at:`, `resume_file:` and `progress.percent:`
  and rewrites `status:`. Run it, `git diff .planning/STATE.md`, restore all four by hand.
</operational_facts>
